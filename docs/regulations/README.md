## 新增法規文件格式

每項法規文件至少應包含：

1. 法規目的與範圍。
2. 功能 ID。
3. 使用者操作流程。
4. 模型輸入與篩選規則。
5. 計算方法、單位與判定條件。
6. Revit 產出物。
7. 程式類別與責任。
8. Session 或資料生命週期。
9. 失敗條件與限制。
10. 測試案例。
